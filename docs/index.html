arquitetura

Como funciona

Duas camadas. A resposta ao cidadão nunca é gerada livremente por IA: o conteúdo vem sempre da base verificada.

Núcleo (avaliado pela GS)

  • Terminal, offline, só Python 3.9+
  • Busca por palavras-chave com pontuação e índice invertido
  • Grafo de assuntos e Dijkstra
  • Dois formatos de resposta
  • Trata entrada vazia, ambígua e sem base

Produto (diferencial)

  • Bot no Telegram (texto, voz, foto, PDF)
  • Roteador com Gemini e reserva por regras
  • Cofre criptografado (AES-256-GCM)
  • Tarefas, lembretes e resumo da manhã
  • Painel web / Mini App

Regra de decisão da busca

  • Inválida: pede de novo
  • Boa correspondência: responde
  • Empate: escolher entre até 3
  • Sem base: avisa e aponta o gov.br

quickstart

Como rodar o núcleo

Só Python 3.9 ou superior. Sem chaves, sem internet, sem instalar nada.

$ git clone https://github.com/JFrois/GlobalSolution_CitizenTech.git $ cd GlobalSolution_CitizenTech $ python src/sistema.py # menu: digite sua pergunta $ python src/sistema.py --avaliar # acerto e tempo médio $ python -m unittest discover -s testes -t .

O bot, o painel e o cofre ficam no modo --servidor e exigem o ambiente descrito no README do repositório.
