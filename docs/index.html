Como funciona

O projeto tem duas camadas. A resposta ao cidadão nunca é gerada livremente por IA: o conteúdo vem sempre da base verificada.

Núcleo (avaliado pela GS)

  • Roda no terminal, offline, só com Python 3.9+
  • Busca por palavras-chave com pontuação, índice invertido, sinônimos
  • Grafo de assuntos e Dijkstra para navegar entre temas
  • Dois formatos de resposta (resumido e passo a passo)
  • Trata entrada vazia, ambígua e sem base

Produto (diferencial)

  • Bot no Telegram (texto, voz, foto, PDF)
  • Roteador com Gemini e reserva por regras
  • Cofre de documentos criptografado (AES-256-GCM)
  • Tarefas, lembretes e resumo da manhã
  • Painel web / Mini App do Telegram

Decisão da busca

  • Entrada inválida: pede de novo
  • Boa correspondência: responde
  • Empate: pede para escolher entre até 3
  • Sem base: avisa e aponta o gov.br

Como rodar o núcleo

Só Python 3.9 ou superior. Sem chaves, sem internet, sem instalar nada.

git clone https://github.com/JFrois/GlobalSolution_CitizenTech.git
cd GlobalSolution_CitizenTech
python src/sistema.py            # menu interativo: digite sua pergunta
python src/sistema.py --avaliar  # taxa de acerto e tempo médio
python -m unittest discover -s testes -t .   # testes

O bot, o painel e o cofre ficam no modo --servidor e exigem o ambiente descrito no README do repositório.
